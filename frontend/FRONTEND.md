## Forgot Password flow

1. Go to '/forgot_password'
2. Enter any email (e.g. 'test@example.com') → Click "Send reset code"
3. → Moves to the OTP screen → Click "Confirm code"(no digits enter required)
4. → Moves to '/reset_password' → Enter any password that meets the requirements
   (≥8 characters, one uppercase letter, one number, one special character) in both
   the New Password and Confirm Password fields → Click "Set new password"
5. → Moves to '/login'

## Register flow

1. Go to '/register'
2. Pick a role (Guest/Coordinator), fill in Full Name, Email, and any Password
   (no strength requirement), check the Terms box → Click "Create account"
3. → Moves to '/verify' → Click "Verify email" (no digits required)
4. → Moves to '/success'
